# new-ecommerce

Full-stack ecommerce app: `server/` (Express + TypeScript + MongoDB) and `frontend/` (Next.js + TypeScript).

**Every feature added to this project must follow the MVC pattern described in `docs/ARCHITECTURE.md`.** Read that file before adding backend routes/controllers or frontend components/state. Progress and decisions are logged in `docs/PROGRESS.md` — update it when you finish a feature.
