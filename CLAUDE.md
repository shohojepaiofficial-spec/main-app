# new-ecommerce

Full-stack ecommerce app: `server/` (Express + TypeScript + MongoDB) and `frontend/` (Next.js + TypeScript).

**Every feature added to this project must follow the MVC pattern described in `docs/ARCHITECTURE.md`.** Read that file before adding backend routes/controllers or frontend components/state. Open/done work is tracked in `docs/STATUS.md` (task IDs `WORK-xx` / `SEC-xx`); the dated history is `docs/PROGRESS.md`. When you finish a feature, update its row in STATUS.md and add a PROGRESS.md entry. Don't create other tracking files.
